# 어둠 속 탈출

p5.js로 만든 타일 기반 탈출 게임의 웹 버전 골격입니다. 열쇠를 찾고 문을 연 뒤, BFS 최단 경로로 추격하는 아오오니를 피해 출구로 이동하세요.

## 실행

브라우저 보안 정책 때문에 `index.html`을 파일로 직접 열기보다 로컬 서버에서 실행하는 편이 좋습니다.

```powershell
npx serve .
```

명령어가 표시하는 주소(일반적으로 `http://localhost:3000`)를 브라우저에서 여세요.

## 조작

- `W` `A` `S` `D`: 이동
- `E`: 현재 칸 조사 또는 바라보는 방향의 문 열기
- `R`: 게임 재시작
- `전체 화면` 버튼: 브라우저 전체 화면 전환

## 프로젝트 구조

- `src/game.js`: 30×30 2차원 맵, 플레이어, 상호작용, Queue 기반 BFS 괴물 AI
- `src/main.js`: 화면에 게임을 연결하는 진입점
- `styles.css`: 게임 페이지 UI와 반응형 스타일
- `images/`: 기존 스프라이트 PNG를 넣는 폴더

스프라이트가 없는 상태에서도 임시 캐릭터가 표시되어, 먼저 게임 규칙과 맵을 편하게 개발할 수 있습니다.

## 타일 코드

- `0`: 길, `1`: 벽, `2`: 열쇠, `3`: 잠긴 문
- `4`: 출구, `5`: 열린 문, `6`: 계단

현재 맵에는 실제 플레이를 위해 시작 구역의 `(10, 3)`에 열쇠, 우측 하단 `(28, 28)`에 출구를 배치합니다. 아오오니는 `(15, 12)`에서 대기하다가 첫 잠긴 문을 열면 추격을 시작합니다.

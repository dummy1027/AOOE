# 스프라이트 폴더

이 폴더에 기존 p5.js 프로젝트의 캐릭터 이미지를 넣으면 자동으로 사용됩니다.

- `A1.png` ~ `A4.png`: 왼쪽 이동
- `D1.png` ~ `D4.png`: 오른쪽 이동
- `S1.png` ~ `S4.png`: 아래쪽 이동
- `W1.png` ~ `W4.png`: 위쪽 이동

`6_아주 아주 무C무C하고 중yo한 사진들_260829` 폴더의 16개 PNG를 이 폴더로 복사해 연결했습니다. 한 칸 이동은 정확히 12 게임 프레임으로 보간되며, 방향별 4장 스프라이트는 각각 3프레임씩 재생됩니다. 이미지가 없어도 임시 원형 캐릭터로 게임은 실행됩니다.
